Fattura elettronica per forfettari gratis: come generarla e inviarla

Ultimo controllo: 4 novembre 2026 · Lettura: circa 3 min

Dal 2024 in generale tutti i forfettari devono emettere fatture elettroniche. Non è necessario pagare un abbonamento: l'Agenzia delle Entrate mette a disposizione strumenti gratuiti. Questa guida spiega le opzioni, i passaggi e le cautele. I dettagli operativi possono cambiare: verifica sempre le istruzioni aggiornate sul sito dell'Agenzia e con il tuo commercialista.

Cosa significa «fattura elettronica»

La fattura elettronica non è un PDF: è un file in formato XML con una struttura definita. Quel file viene trasmesso al Sistema di Interscambio (SDI), che lo controlla e lo recapita al cliente. Il PDF che mandi al cliente è una copia leggibile; il documento fiscale è il file XML trasmesso.

Le due strade gratuite

  1. Portale «Fatture e Corrispettivi» dell'Agenzia delle Entrate: accedi con le credenziali previste (SPID, CIE o CNS), puoi compilare una fattura direttamente online oppure caricare un file XML già pronto. Esiste anche un'applicazione ufficiale per telefono.
  2. PEC: invii il file XML come allegato da una casella PEC all'indirizzo dello SDI. La prima volta lo SDI risponde indicando l'indirizzo da usare per gli invii successivi. Dettagli sul sito dell'Agenzia.

Non servono intermediari a pagamento, anche se esistono. Valuta se ti conviene in base a quante fatture fai e a quanto ti pesa ripetere la procedura.

Dove entra VocePreventivo

VocePreventivo genera il file XML della fattura per chi è in regime forfettario e una copia PDF di cortesia. Non trasmette nulla allo SDI: scarichi il file e lo carichi tu sul portale (o lo mandi via PEC). Non garantisce la conformità fiscale del documento, quindi controlla sempre il risultato prima di inviare. Il portale dell'Agenzia offre strumenti di verifica del file prima dell'invio, che conviene sfruttare.

Il percorso, passo per passo

  1. Prepara la fattura con tutti i dati (cosa scrivere in fattura), il numero (numerazione) e l'eventuale bollo (guida al bollo).
  2. Controlla i dati del cliente: partita IVA o codice fiscale, e, se è un'impresa, codice destinatario o PEC. Per i privati senza codice si usa di norma un valore standard previsto dalle istruzioni tecniche.
  3. Carica il file sul portale (o invialo via PEC).
  4. Attendi le ricevute dello SDI: consegna, mancata consegna o scarto.
  5. Dai al cliente la copia della fattura: se è un consumatore, la copia (anche in PDF) va resa disponibile.
  6. Conserva il file XML (vedi più sotto).

I tempi

In generale la fattura immediata va trasmessa entro pochi giorni dall'operazione: il termine più citato è di 12 giorni. Verifica il termine vigente e come si calcola nel tuo caso, soprattutto per lavori a cavallo di fine mese o di fine anno.

Le ricevute dello SDI

Dopo l'invio, lo SDI risponde con una ricevuta. Se la fattura è consegnata, bene. Se c'è una mancata consegna (per esempio il canale del cliente non è attivo), in generale la fattura si considera comunque emessa, ma conviene avvisare il cliente e dargli copia. Se è scartata, vedi come annullare una fattura già emessa e correggi l'errore.

Conservazione

Le fatture elettroniche vanno conservate secondo le regole vigenti. L'Agenzia delle Entrate mette a disposizione un servizio gratuito di conservazione, a cui si aderisce dal portale; in alternativa ci si può rivolgere a un conservatore. Una cartella sul telefono o sul computer in generale non basta: chiedi al tuo commercialista come organizzarti.

Verifica sempre con il tuo commercialista.

Questa guida è informativa: non è consulenza fiscale e non sostituisce il parere di un professionista. Le regole possono cambiare e il tuo caso può avere particolarità. Gli importi e i termini citati sono indicativi: controllali prima di applicarli.

Domande frequenti

La fattura elettronica per forfettari è gratis?

Gli strumenti dell'Agenzia delle Entrate sono gratuiti. Se usi un programma o un intermediario, i costi dipendono dal servizio scelto.

Il PDF vale come fattura?

No, in generale il documento fiscale è il file XML trasmesso tramite SDI; il PDF è una copia leggibile.

VocePreventivo invia le fatture per me?

No. Genera l'XML e la copia PDF, ma l'invio allo SDI lo fai tu, dal portale o via PEC.

Cosa faccio se il cliente non ha PEC o codice destinatario?

In generale la fattura può essere trasmessa ugualmente e il cliente la trova nella sua area riservata. Chiedi conferma al commercialista.
